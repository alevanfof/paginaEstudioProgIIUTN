# paginaEstudioProgIIUTN

Presentación interactiva de Programación II para las unidades 5 a 8. Esta carpeta contiene únicamente la página web y los dos audios que reproduce.

## Publicar con Vercel

Importá el repositorio en Vercel y configurá **Root Directory** como `paginaProgII`. No necesita framework ni comando de build; `index.html` es la página de entrada.

## Publicar en GitHub

Desde la raíz del proyecto, inicializá el repositorio y agregá solo esta carpeta. Así, los materiales Java y los demás documentos de estudio quedan fuera de lo que se publica:

```powershell
git add paginaProgII
git commit -m "Add interactive Programación II study page"
git push -u origin main
```
